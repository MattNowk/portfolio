# portfolio
Mon Portfolio de développeur

## Lancer le projet

```
npm install
npm run dev
```

## Structure

- `src/data/sections.js` : liste des sections (menu, barre de progression).
- `src/sections/` : contenu de chaque section.
- `src/components/` : éléments communs (header, footer, barre de progression…).
- `src/hooks/` : logique réutilisable (thème, suivi du défilement).
- `src/index.css` : couleurs des thèmes et styles globaux.
